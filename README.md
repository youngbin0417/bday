# Pour mon chat

프랑스어 생일 편지 웹페이지입니다. 서울 픽셀 배경, 커플 캐릭터, 열리는 편지, 터치하면 도트 하트가 나오는 장미, 생일 케이크가 포함되어 있습니다.

## 다운로드

[웹페이지 ZIP 다운로드](https://github.com/youngbin0417/bday/archive/refs/heads/main.zip)

1. ZIP을 다운로드하고 압축을 풉니다.
2. `bday-main/index.html`을 Chrome, Safari 또는 Firefox로 엽니다.

그림과 스크립트가 `index.html`에 모두 포함되어 있어 별도의 설치나 서버가 필요 없습니다. 웹 글꼴을 불러오지 못하면 기본 글꼴로 표시됩니다.

## 수정

`index.html`의 `letter-copy` 영역에서 편지 본문을, `signature`에서 서명을 바꿀 수 있습니다. 현재 본문은 예시 편지입니다.

웹사이트 배포는 설정하지 않았습니다.
